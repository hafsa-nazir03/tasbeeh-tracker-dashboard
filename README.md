# 📿 Tasbeeh Tracker Dashboard

## 📖 Overview

A full-stack **Tasbeeh Tracker Dashboard** built with **Node.js**, **Express.js**, **Vanilla JavaScript**, **HTML**, **CSS**, and **Chart.js**.

The application allows users to create and manage Tasbeehs, set targets, select categories, count Dhikr, and view their Tasbeeh data through an interactive dashboard with charts and statistics.

The dashboard fetches real data from the backend and allows users to filter the data by category, dynamically updating the charts and statistics.

---

## ✨ Features

- 📿 Add new Tasbeehs
- 🎯 Set a target for each Tasbeeh
- 🏷️ Categorize Tasbeehs
- ✏️ Update existing Tasbeehs
- 🗑️ Delete existing Tasbeehs
- 🔢 Dedicated Tasbeeh counter
- 🔄 Reset counter
- 📊 Interactive dashboard
- 📈 Bar chart visualization
- 🍩 Doughnut chart visualization
- 🎯 Target comparison chart
- 🔢 Total Tasbeehs statistic
- 🎯 Total Target statistic
- 📊 Average Target statistic
- 🔎 Interactive category filter
- ⚡ Dynamic chart updates without page reload
- 📱 Responsive design
- 🌙 Dedicated Virtues of Zikar page

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hafsa-nazir03/tasbeeh-tracker-dashboard.git
```

### 2. Navigate to the backend folder

```bash
cd backend
```

### 3. Install dependencies

```bash
npm install
```
### 4. Start the server

```bash
node server.js
```

The backend will run on:

```
http://localhost:3000
```

### 5. Open the frontend

Open the HTML file in your browser using Live Server or any local development server.
